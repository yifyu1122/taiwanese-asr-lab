# Taiwanese ASR Lab

歡迎來到 **Taiwanese ASR Lab**！這個專案紀錄了我參加 **2026 iThome 鐵人賽** 的相關程式碼與技術筆記。

## 專案簡介

「為什麼英文有成熟的發音檢測工具，台語卻沒有？」

本專案源自於大學畢專的踩坑經驗與技術啟發。在主流語言 AI 蓬勃發展的今天，台語的語音技術仍充滿挑戰。本系列文章與程式碼將帶你一起探索台語自動語音辨識（ASR）的技術細節，並朝著「台語發音檢測」的目標邁進。

在這個專案中，我們不僅會探討現有的強大台語模型（如 MediaTek 的 Breeze ASR、基於 Wav2Vec2 的 CTC 模型），還會深入挖掘以下主題：
- **模型內部觀察**：剖析模型推論過程中的 Hidden States、Logits 與 Frame-level 資訊，為發音檢測鋪路。
- **資料整理實戰**：從台語字典、臺羅拼音出發，建構與清理適合模型輸入的訓練資料。
- **踩坑實錄與微調經驗**：紀錄模型微調過程中遇到的各種狀況（例如：看似完美的 99.34% 準確率背後隱藏的問題）。

目前系列文章正在 [Medium](https://medium.com/@yifyu1122) 上先行連載中，未來也會同步發布至 iThome。
